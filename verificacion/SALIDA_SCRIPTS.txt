NOTAS IMPORTANTES:
================================================================================

1. PRECISIÓN: Todos los resultados se presentan con 4 decimales

2. FÓRMULAS: Se usan solo fórmulas explícitas, NUNCA funciones estadísticas
   - EDA: σ = √[Σ(x-media)²/(n-1)]
   - Dist: F = i/(n+1), x_T = μ - β×ln(-ln(1-1/T))
   - Reg: r = Sxy/√(Sxx×Syy), b₁ = Sxy/Sxx, etc.
   - Series: PM3 = (y_t + y_(t-1) + y_(t-2))/3, etc.

3. MÉTODOS: Se usan métodos estándar internacionales
   - Cuartiles: tipo 7 (equivalente a QUARTILE.INC de Excel)
   - Gumbel: momentos (alternativa a MLE)
   - Regresión: mínimos cuadrados ordinarios (OLS)
   - Series: métodos clásicos sin descomposición STL

4. MUESTRAS PEQUEÑAS: Cada muestra tiene 8-10 datos
   - Apropiadas para verificación manual
   - No necesariamente representativas de toda la serie

5. VALIDACIÓN CRUZADA:
   Si Python = R = App, entonces la app es correcta
